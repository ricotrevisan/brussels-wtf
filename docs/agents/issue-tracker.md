# Issue tracker

GitHub Issues in `RicoTrevisan/brussels-wtf` are the canonical tracker.

- Create one issue per decision or implementation slice.
- Use native sub-issue relationships for Wayfinder maps and their tickets.
- Use native blocking relationships for dependencies.
- Refer to issues by linked title in human-facing prose, not by bare number.
- Apply `ready-for-agent` only when the issue is sufficiently specified for an agent to execute.
- Pull requests are not an issue-triage request surface.
