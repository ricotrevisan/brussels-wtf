# Domain documentation

This is a single-context repository.

- `CONTEXT.md` is the canonical domain glossary. It contains terminology and domain distinctions, not implementation details.
- `docs/adr/` contains architectural decisions that are hard to reverse, surprising without context, and chosen through a real trade-off.
- Read `CONTEXT.md` before planning or changing domain behaviour.
- Update the glossary when a domain term is resolved or its meaning changes.
- Add an ADR only when all three ADR criteria above are met.
