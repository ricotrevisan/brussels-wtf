# City of Brussels agenda text fixtures

Minimal excerpts of `pdftotext -layout` text from official public agendas, kept to the points
each test needs. Lines are verbatim, except that other points are left out, page numbers are
compacted, and a citizen's name is replaced by `M. X`. The repository holds no full source
document.
