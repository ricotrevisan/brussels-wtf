# Uccle agenda excerpts

Minimal excerpts of three official Uccle agendas, kept only to exercise the layout: not
copies of the documents. Every wording line is verbatim, but points are selected and
renumbered and footers show the excerpt's own page count, so these bytes are not the
official text and their pages and points do not cite the originals.

- `2026-10-15-odj.excerpt.txt`: French broken from Dutch by a page, French continuing on the
  next page, a non-votable point.
- `2026-10-15-odjc.excerpt.txt`: the complementary agenda restates the list and inserts a new
  point, moving the next point's number.
- `2026-06-25-odj.excerpt.txt`: the publisher's malformed point 28, kept in place.

Origins: <https://www.uccle.be/fr/ma-commune/le-conseil-communal>. Full-document results are in
`docs/research/2026-11-03-uccle-agenda-layouts.md`. Run the full-document test with
`UCCLE_REAL_AGENDA_DIR` pointing at retained text outside the repository.
